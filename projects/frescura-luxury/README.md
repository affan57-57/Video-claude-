# Frescura Body — Luxury Boutique Ad (HyperFrames)

- `index.html`: the HyperFrames composition (9 scenes, word-level karaoke captions)
- `assets/mix.wav`: the final audio mix (built by `scripts/frescura-luxury/mix.py`)
- Preview: `npx hyperframes render -q draft`; final: `npx hyperframes render -q high`
