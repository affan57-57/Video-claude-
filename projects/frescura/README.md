# Frescura Body: HyperFrames ad (9:16, 40 s)

- `index.html` + `compositions/*.html` are generated by `scripts/frescura_build.py` from `scripts/frescura_scenes/*.html`.
- Audio (`assets/audio/*.wav`) is not committed. To rebuild it:
  1. Voice: demucs `htdemucs_ft` vocals → EQ/de-ess/compress chain → `scripts/frescura_voice.py` (pause trim) → rubberband tempo 1.25 → loudnorm -14 LUFS.
  2. SFX + music bed: `python scripts/frescura_sfx.py assets/audio 42`.
- Preview: `npx hyperframes render -q draft`. Final: `npx hyperframes render -q delivery`.
